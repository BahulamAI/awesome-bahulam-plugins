# Scene DSL — the source of truth

Every scene lives in a folder under the user's working directory:

```
<cwd>/<slug>/
├── scene.json    # DSL — the source of truth
├── index.html    # compiled Three.js document — regenerated on every mutation
├── assets/       # imported/generated meshes, textures, HDRI
└── snapshots/    # timestamped scene.json snapshots
```

Tools mutate **scene.json** only. `index.html` is regenerated by
`tools/scene-compile.mjs` on every save. Never edit `index.html` by hand —
it will be overwritten on the next mutation.

## Top-level shape

```jsonc
{
  "version": 1,
  "slug": "cafe-corner",
  "title": "Cafe Corner",
  "width": 1280,
  "height": 720,
  "background": "#0b1020",           // or { "hdri": "assets/env.hdr", "intensity": 1 }
  "tone": { "mapping": "ACESFilmic", "exposure": 1.0 },
  "camera": {
    "type": "perspective",
    "fov": 45, "near": 0.1, "far": 1000,
    "position": [5, 4, 8],
    "target": [0, 1, 0],
    "controls": "orbit"              // "orbit" | "first-person" | "none"
  },
  "materials": {
    "default":     { "type": "standard", "color": "#8090a0", "roughness": 0.6, "metalness": 0.1 },
    "leather_red": { "type": "physical", "color": "#8b1a1a", "roughness": 0.7, "metalness": 0, "clearcoat": 0.2 }
  },
  "nodes": [
    { "id": "floor",  "type": "mesh",  "geometry": {"type":"plane","params":{"width":20,"height":20}}, "materialId": "default", "rotation":[-1.5708,0,0], "receiveShadow": true },
    { "id": "table",  "type": "mesh",  "geometry": {"type":"box","params":{"width":1.6,"height":0.05,"depth":0.9}}, "materialId": "default", "position":[0,0.72,0] },
    { "id": "chair1", "type": "mesh",  "geometry": {"type":"box","params":{"width":0.45,"height":0.9,"depth":0.45}}, "materialId": "leather_red", "position":[0.9,0.45,0] },
    { "id": "sun",    "type": "light", "light": {"type":"directional","color":"#ffeedd","intensity":2.5,"position":[5,10,7],"castShadow":true} }
  ],
  "scripts": [],
  "physics": [],
  "post":    {},
  "meta":    { "created_at": "...", "updated_at": "..." }
}
```

## Node types

| type | required extra fields |
|---|---|
| `mesh` | `geometry: {type, params}`, `materialId` |
| `group` | (none — pure container) |
| `light` | `light: {type, color, intensity, ...}` |
| `helper` | `helper: {type, ...}` |
| `instanced` | `geometry`, `materialId`, `count`, `instances: [{position, rotation, scale, color?}]` |
| `points` | `geometry` (usually buffer), `materialId` (`type: "points"`) |
| `line` | `geometry`, `materialId` (`type: "line"`), `mode: "line"|"segments"|"loop"` |
| `gltf` | `asset: "assets/model.glb"` |
| `sprite` | `materialId` (`type: "basic"` with a texture) |
| `text` | (reserved — not yet compiled) |

Every node accepts: `id` (required), `name`, `parent`, `position`, `rotation`,
`scale`, `castShadow`, `receiveShadow`, `visible`.

## Geometry types

`box | sphere | cylinder | cone | torus | torusKnot | plane | circle | buffer`

Each has a `params` object matching the Three.js constructor:

- `box`: `{width, height, depth, widthSegments?, heightSegments?, depthSegments?}`
- `sphere`: `{radius, widthSegments?, heightSegments?}`
- `cylinder`: `{radiusTop, radiusBottom, height, radialSegments?}`
- `cone`: `{radius, height, radialSegments?}`
- `torus`: `{radius, tube, radialSegments?, tubularSegments?}`
- `plane`: `{width, height, widthSegments?, heightSegments?}`
- `circle`: `{radius, segments?}`
- `buffer`: `{positions, normals?, uvs?, indices?}` — raw arrays

## Material types

`standard | physical | basic | lambert | phong | toon | normal | points | line`

Common fields: `color`, `opacity`, `transparent`, `side`, `wireframe`,
`emissive`, `emissiveIntensity`.

PBR (standard/physical): `roughness`, `metalness`, `envMapIntensity`.
Physical-only: `clearcoat`, `transmission`, `ior`, `thickness`.

Texture slots (paths relative to scene folder or absolute URLs):
`map`, `normalMap`, `roughnessMap`, `metalnessMap`, `emissiveMap`,
`aoMap`, `alphaMap`.

## Light types

| type | fields |
|---|---|
| `ambient` | `color`, `intensity` |
| `directional` | `color`, `intensity`, `position`, `target?`, `castShadow?` |
| `point` | `color`, `intensity`, `position`, `distance?`, `decay?` |
| `spot` | `color`, `intensity`, `position`, `target?`, `angle?`, `penumbra?`, `distance?`, `decay?` |
| `hemisphere` | `color`, `groundColor`, `intensity` |
| `rectarea` | `color`, `intensity`, `width`, `height`, `position` |

## Scripts (event/tick code)

```jsonc
"scripts": [
  { "id": "spin_table", "target": "table", "event": "tick", "code": "target.rotation.y += 0.5 * (dt||0.016);" }
]
```

The runtime injects `target`, `scene`, `dt` (delta seconds), and Three.js
globals into the closure. Kept intentionally minimal — for anything
complex use the developer fallback path.

## Version + migration

The DSL is versioned via the top-level `version` field. Current version: `1`.
Compilers should tolerate unknown fields (forward-compatible) and log a
warning on unknown node types.
