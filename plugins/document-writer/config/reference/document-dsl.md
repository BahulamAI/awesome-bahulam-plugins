# Document DSL — source of truth

Every document lives in a folder under the user's working directory:

```
<cwd>/<slug>/
├── document.json     # DSL — source of truth
├── document.md       # auto-regenerated on every mutation
├── refs.bib          # auto-regenerated on every mutation
├── sources/          # ingested PDFs, notes, URL snapshots, data files
│   ├── smith2024.pdf
│   ├── notes/        # freestanding markdown notes
│   └── extracted/    # extracted text + figures per source
├── figures/          # curated figures for the paper
├── snapshots/        # timestamped document.json copies
└── exports/          # generated .tex / .pdf / .docx / .xml on demand
```

Tools mutate **document.json** only. `document.md` and `refs.bib` are
regenerated by `tools/document-compile.mjs` on every save. Never edit
either by hand — they'll be overwritten on the next mutation.

## Field semantics

**outline[].id** — stable across the document's lifetime; used by every
tool that touches a section. Prefer semantic ids (`method`, `results`)
over auto-generated.

**sections[id]** — populated as the Draft Agent writes prose. `.cites`
is derived by parsing `[ref_id]` tokens in `.content` and matching
against `references`; unknown ids surface as `unresolved_cite_candidates`
in tool responses so the Cite Agent can resolve them.

**references[id]** — BibTeX-shaped: `{ type, fields: { authors, title,
year, doi, url, booktitle | journal, ... } }`. `authors` is an array;
the compiler joins with ` and ` for BibTeX and `, ` for Markdown.

**figures[]** — `id` (referenced by section.figures), `path` (relative
to the document folder), `caption` (short, printed with the figure),
`description` (longer, from Vision Analyst — informational, not printed),
`placement` (LaTeX float placement: h/t/b/H).

**sources[id]** — `kind` is one of pdf / url / note / experiment.
`extracted_path` points at a JSON blob written by the PDF provider
(`sources/extracted/<id>.json`) — the Draft Agent read_files this
to work from the source text.

**claims[]** — every quantitative or verifiable assertion in the paper.
`verified: true` iff `verification.verdict === "supported"`. The
`compile_document` tool REFUSES non-`md` targets when unverified
claims exist unless `allow_unsupported_claims: true`.

**patent** — populated only when `kind === "patent_application"`.
Phase 2 completes the patent-only flow (Prior-Art + Claim-Author agents,
USPTO XML compile target).

## Watermark

`meta.watermark` marks the compiled output as DRAFT / CONFIDENTIAL /
etc. The compiler emits it into every target: Markdown blockquote,
LaTeX `draftwatermark` package, USPTO XML `us-publication-status`
element.

Three states the compiler distinguishes:

| `meta.watermark` value | Compiler behavior |
|---|---|
| absent (never set)         | **Auto-DRAFT** if `list_unsupported_claims.count > 0`; otherwise no watermark |
| `null` (explicit opt-out)  | No watermark, ever — even with unverified claims |
| `{text, opacity?, angle?, color?}` | Emitted as-is on every compile |

Set via `set_watermark(slug, text, opacity?, angle?, color?)`. Pass
`text: null` (or `""`) to clear + opt out of auto-DRAFT. Owned by the
**Style Agent**.

## Version + migration

DSL `version` field is `1`. Compilers tolerate unknown fields (forward-
compatible) so a Phase 2-authored doc still loads under Phase 1 (with
patent-only tools inaccessible).
